# Wireless Networking

## 📌 Overview

This folder contains my hands-on wireless networking labs created using Cisco Packet Tracer. These labs cover Wireless Access Point configuration, wireless connectivity, DHCP, dynamic IP addressing, and communication between wired and wireless devices.

## 📂 Labs

### 1. Wireless Access Point Lab

This lab demonstrates the configuration of a Wireless Access Point. A secure wireless network was created by configuring an SSID and password, connecting multiple wireless devices, and verifying network connectivity.

**Key Tasks:**
- Configure a Wireless Access Point
- Create and configure an SSID
- Secure the wireless network with a password
- Connect wireless clients to the network
- Verify connectivity using ping

### 2. Wireless Network with DHCP Lab

This lab demonstrates the configuration of a wireless network using a DHCP server, switch, and Wireless Access Point. Wireless devices were connected through the Access Point, while IP addresses were assigned dynamically using DHCP.

**Key Tasks:**
- Configure DHCP for dynamic IP addressing
- Configure a Wireless Access Point
- Create and configure an SSID
- Connect Laptop, Tablet, and Printer wirelessly
- Connect PCs through the switch
- Verify communication between wired and wireless devices
