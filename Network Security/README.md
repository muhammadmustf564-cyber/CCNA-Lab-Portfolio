# Network Security

This section contains practical networking security labs implemented using Cisco Packet Tracer. These projects focus on securing network access and controlling traffic through security configurations.

## Labs

### .Port Security
Implemented switch port security using sticky MAC addresses, maximum MAC address limits, and shutdown violation mode to prevent unauthorized device access.


### .Standard ACL
Implemented Standard Access Control Lists to restrict traffic from specific networks and hosts while allowing permitted traffic.

## Skills Covered
- Switch Port Security
- MAC Address Filtering
- Standard Access Control Lists (ACLs)
- Traffic Filtering
- Network Access Control
- Cisco IOS Configuration and Verification

**Tool:** Cisco Packet Tracer
