# ```VLAN-and-Trunking```

A hands-on Cisco Packet Tracer lab demonstrating **VLAN segmentation and trunking** across two switches. The lab includes three VLANs with multiple end devices, access-port assignments, and an inter-switch trunk link. Connectivity testing verifies **same-VLAN communication** and **isolation between different VLANs**.

**Skills:** VLANs · Trunking · Access Ports · Layer 2 Switching · Network Segmentation · Connectivity Testing

# ```🔄 VTP Lab```

This lab demonstrates the practical implementation of **VLAN Trunking Protocol (VTP)** in a multi-switch network using **Cisco Packet Tracer**.

In this lab, different switches were configured in **VTP Server, Transparent, and Client modes** to understand how VLAN information is managed and propagated across a switched network. VLANs were created and verified on the switches, while **trunk links** were configured to support communication between the switches.

The lab also includes verification of **VTP status, VLAN information, and trunk connectivity** using Cisco IOS commands.

### 🛠️ Tools & Technologies

`Cisco Packet Tracer` • `Cisco IOS` • `VLAN` • `VTP` • `802.1Q Trunking`

### 🎯 Key Learning

Gained practical experience with **VTP modes, VLAN management, VLAN propagation, and trunking** in a Cisco switching environment.
