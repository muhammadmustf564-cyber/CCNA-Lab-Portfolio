# ```VLAN-and-Trunking```

A hands-on Cisco Packet Tracer lab demonstrating **VLAN segmentation and trunking** across two switches. The lab includes three VLANs with multiple end devices, access-port assignments, and an inter-switch trunk link. Connectivity testing verifies **same-VLAN communication** and **isolation between different VLANs**.

**Skills:** VLANs · Trunking · Access Ports · Layer 2 Switching · Network Segmentation · Connectivity Testing
