### OSPF Routing

This folder contains my **OSPF multi-area routing lab** created in Cisco Packet Tracer.

The lab demonstrates **OSPF Area 0 (Backbone Area), Area 1, OSPF neighbor relationships, dynamic route learning, and Router4 acting as an Area Border Router (ABR)**.

**Topics:** OSPF | Area 0 | Area 1 | ABR | Dynamic Routing | IPv4




###  OSPF-RIP Redistribution Using ASBR

This lab demonstrates **route redistribution between OSPF and RIP using an ASBR (Autonomous System Boundary Router) in Cisco Packet Tracer**.

**R0** acts as the ASBR and redistributes:

**- RIP routes → OSPF**
**- OSPF routes → RIP**

The configuration was verified using routing tables, OSPF neighbors, routing protocols, and end-to-end ping tests between both routing domains.

**Tools**: Cisco Packet Tracer | Cisco IOS
