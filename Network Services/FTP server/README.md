# 📁 FTP Server Lab

## Objective

Configure and test an FTP Server in Cisco Packet Tracer and verify communication between network clients and the server.

## Devices Used

- 1 Cisco Switch
- 1 FTP Server
- 2 PCs
- 1 Laptop

## Lab Focus

- FTP Server configuration
- Client-to-server communication
- FTP commands
- Network connectivity testing

## Configuration

- Connected two PCs, one laptop, and the FTP server through a switch
- Configured IP addresses for the network devices
- Configured the FTP service on the server
- Established communication between clients and the FTP server
- Used FTP commands to interact with the server

## Verification

- Tested network connectivity using "ping"
- Verified FTP communication from a client PC
- Confirmed successful communication between clients and the FTP server

## Tool

Cisco Packet Tracer

## Result

The FTP Server was successfully configured and tested. The connected PCs and laptop were able to communicate with the FTP server, demonstrating basic FTP-based client-to-server communication in a network environment.
