# 📧 Email Server Lab

## Objective

Configure and test an **Email Server** in **Cisco Packet Tracer**, including **DHCP-based IP addressing** and **email communication** between client PCs.

## Devices Used

**- DHCP Server**
**- Email Server**
**- Client PCs**
**- Network Switch**

## Lab Focus

**- DHCP Server configuration**
**- Email Server configuration**
**- Email account creation**
**- Email client configuration**
**- Client-to-server communication**
**- Email transmission and verification**

## Configuration

- Configured the **DHCP Server** to dynamically assign **IP addresses** to client PCs
- Configured the **Email Server**
- Created and configured **email accounts** for client PCs
- Configured **email client settings** on the PCs
- Established communication between the **client PCs** and the **Email Server**
- Sent an email from **PC2 → PC0**

## Verification

- Verified **dynamic IP address assignment** using DHCP
- Tested **network connectivity**
- Successfully sent an email from **PC2 to PC0**
- Successfully received and opened the email on **PC0**
- Verified **client-to-server email communication**

## Tool

**Cisco Packet Tracer**

## Result

The **DHCP and Email services** were successfully configured and tested. Client PCs received **IP addresses dynamically** and were able to communicate through the configured **Email Server**, successfully **sending and receiving emails**.
