# Wireless Access Point Lab

## 📌 Overview

This lab demonstrates the configuration of a Wireless Access Point in Cisco Packet Tracer. A secure wireless network was created by configuring the SSID and password, connecting multiple wireless devices, and verifying network connectivity.

## 🎯 Objectives

* Configure a Wireless Access Point
* Create and configure an SSID
* Secure the wireless network with a password
* Connect wireless clients to the network
* Verify connectivity using the ping command

## 🛠️ Tools Used

* Cisco Packet Tracer

## 📂 Screenshots

* Network Topology
* Access Point Configuration
* Wireless Client Connection
* Successful Ping Test
* Wireless Printer Connection

## ✅ Result
The Wireless Access Point was successfully configured. All wireless devices connected to the configured SSID using the correct password, and network connectivity was verified through successful ping tests.
